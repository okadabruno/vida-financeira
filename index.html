Dúvidas frequentes

Antes de começar

Veja como funciona e o que você precisa para utilizar a planilha.

Preciso saber Excel?

Não é necessário ser especialista. A planilha possui instruções para orientar o preenchimento. É recomendável ter conhecimentos básicos de utilização do Excel.

Existe mensalidade?

Não. A versão Premium é apresentada como compra única, sem mensalidade.

Posso personalizar categorias e contas?

Sim. A versão Premium possui uma aba Configurações para ajustar categorias, contas e cartões.

Funciona no celular ou no Excel para a Web?

A versão Premium utiliza macros VBA para algumas automações. As macros não são executadas no Excel para a Web nem nos aplicativos móveis. Para aproveitar esses recursos, utilize o aplicativo de desktop do Excel em um computador.

Preciso habilitar macros?

Sim, para utilizar as automações da aba Recorrências. Habilite macros somente em arquivos cuja origem você confirmou e nos quais confia. Não é recomendado habilitar todas as macros do Excel indiscriminadamente.

O que recebo após a compra?

Você receberá um arquivo Excel habilitado para macros (.xlsm), com os recursos da versão Premium, para utilizar no Excel instalado no computador.

A planilha importa dados do banco automaticamente?

Não. Receitas, despesas, saldos, contas, cartões e investimentos devem ser cadastrados e atualizados pelo próprio usuário.

Qual versão do Excel é necessária?

Recomendamos utilizar o Microsoft Excel instalado em um computador com Windows. A compatibilidade com outras versões e sistemas deve ser confirmada antes da compra; não anunciamos aqui compatibilidade específica ainda não validada.
